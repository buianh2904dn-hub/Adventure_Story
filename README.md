# 🏔️ Text-Based Adventure Story

An interactive, text-driven decision game written in Python. Step into the shoes of a treasure hunter, venture deep into a mysterious monster-infested mountain, and try your luck!

#### ✨ Key Features
* **Narrative-Driven Gameplay:** Immersive storytelling with timed text prompts using Python's `time` and `random` libraries.
* **High Stakes Choices:** Make a split-second choice between left or right paths that lead either to legendary riches or a hungry monster!
* **Input Validation:** Built-in handling for invalid choices and repeated typos.
